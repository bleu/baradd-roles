# BARAD — starter brand assets

This is an implementation starter pack, not a finished production identity system.

## Files
- `svg/barad-mark.svg` — standalone fortress mark, transparent background.
- `svg/barad-wordmark.svg` — centered mark + BARAD wordmark.
- `svg/barad-horizontal.svg` — horizontal navbar lockup.
- `svg/favicon.svg` — dark favicon.
- `png/app-icon-dark.png` — dark app icon.
- `png/app-icon-light.png` — light app icon.
- `png/app-icon-gold.png` — gold-accent app icon.
- `png/favicon-*.png` — common favicon/PWA sizes.
- `backgrounds/barad-citadel-hero.jpg` — atmospheric hero image starter.
- `design-tokens.css` — palette and basic design tokens.

## Fonts
Use Cinzel (or Marcellus) for display headings and Inter for interface/body text.
The SVG wordmarks use a Cinzel/Georgia fallback stack; for exact brand typography,
load Cinzel in the site and consider converting the wordmark text to paths before production.

## Suggested usage
- Navbar: `svg/barad-horizontal.svg`
- Hero/brand section: `svg/barad-wordmark.svg`
- Browser tab: `svg/favicon.svg` or `png/favicon-32.png`
- App icon: choose one of the 1024px PNG variants.
- Hero background: `backgrounds/barad-citadel-hero.jpg`

The fortress symbol is an original geometric interpretation of the negative-space castle direction.
Review it at small sizes and adjust the gate/tower geometry to your preference before final brand lock.
